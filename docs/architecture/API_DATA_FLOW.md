# DGU API and Data Flow

All endpoint paths below are source-derived. Credentials are intentionally omitted. Live status claims are only included where the repository's read-only live script or an explicit live check verified them.

## Shared transport

`components/dgu-api-transport.ts:4-35` maps feed names to PHP filenames and exposes:

- `liveDguApiUrl(feed, override)`: validates absolute HTTPS URLs (localhost HTTP is allowed), rejects credentials/fragments, and selects the configured override, base URL, or original DGU API.
- `clientDguApiUrl(feed, override)`: returns `/api/dgu-${feed}/` in development and the live absolute URL in production/static export.
- `readDguApiJson(response, label)`: rejects non-2xx responses and invalid/404 HTML, strips a BOM, and parses JSON.

Development rewrites are in `next.config.ts:15-31`; production export has no Next server proxy, so browser-side production requests use the live endpoint and depend on its CORS/authentication behavior.

## Field and fallback rules

1. `apiFields`, `apiValue`, `apiPlain`, `apiText`, `apiMedia` in `dgu-content-api.ts` normalize casing, text, HTML/media and aliases.
2. API-only page renderers intentionally omit missing API blocks. They do not append the old local page's content to partial API results.
3. Presentation-only assets may remain when they do not claim to be API records: route shells, headings, artwork, approved homepage copy, video controls and empty-state copy.
4. Placement student records, companies, statistics, taglines and descriptions must come from the placement response for API scopes. `SchoolPlacementsSection.tsx` keeps static defaults only in its non-API branch.
5. `readDguApiJson` rejects a website 404 page returned with HTTP 200, preventing false success.

## Live versus fixture evidence

The regression scripts use fixtures/mocks and prove contracts, parser behavior, fallback exclusion, retry and route mapping. `scripts/verify-dgu-apis.cjs` is the read-only live verifier and reports statuses, field names and counts without printing credentials or records. A passing fixture test does not prove current production content placement. Browser visual/API-console verification was not part of this documentation task.
